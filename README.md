## 🚨 What is BEACON?

BEACON is an **Android-based Emergency Alert System** built for the moments when traditional communication dies.

Earthquakes. Floods. Remote treks. Tunnel collapses. Crowd disasters.  
**When cell towers go dark and the internet vanishes — BEACON works.**

---

## ⚡ How It Works

One tap. That's all.  
BEACON automatically chooses the fastest path to deliver your alert:

| Mode | When? | How? |
|------|-------|------|
| ☁️ **Online** | Internet available | Real-time cloud sync (Supabase) |
| 📶 **Offline** | Internet dead, GSM alive | SMS fallback |
| 🔁 **P2P Mesh** | No internet, no GSM | Device-to-device via Wi-Fi Direct / Bluetooth |

**No manual switching. No technical skills needed. Just tap SOS and go.**

## 📍 What an Alert Carries

- 🆔 Unique ID (no loops)
- 🔴 Severity Level (Minor, Major, Disaster)
- 🕒 Timestamp
- 📌 GPS Coordinates
- 👤 Sender Info
- ✅ Acknowledgment Status

---

## 🛠️ Built With

- **Kotlin** + **Jetpack Compose** — Modern, reactive UI
- **Supabase** — Real-time cloud sync, auth, PostgreSQL
- **Room Database** — Offline-first local storage
- **Nearby Connections API** — P2P mesh magic
- **Wi-Fi Direct** + **Bluetooth LE** — Device-to-device
- **SMS Manager** — When all else fails

**Min SDK:** Android 7.0 (2+ billion devices supported)
